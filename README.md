
# 🌍 Информационное приложение «Города и Страны»

## 🎯 О проекте
Десктопное приложение на Python (PyQt6) для быстрого поиска качественной информации о странах и городах. Создано для того, чтобы избавить пользователя от необходимости искать данные по разным сайтам и отвлекаться на рекламу.

## 🛠 Технический стек
*   **Язык:** Python
*   **Интерфейс:** PyQt6 (QMainWindow, QMessageBox, QTableWidget, QLineEdit и др.)
*   **Работа с данными:** SQLite3 (для хранения истории запросов), JSON (парсинг ответов API).
*   **Внешние API и библиотеки:**
    *   `requests` — сбор данных с API (OpenCage, Open-Meteo, ER-API).
    *   `countryinfo` — получение информации о странах.
    *   `translate` — перевод данных на русский/английский.
    *   `pytz` — работа с часовыми поясами.
    *   `pyqtgraph` — построение графиков погоды.
    *   `webbrowser` — открытие интерактивных карт OpenStreetMap.

## 💡 Ключевые навыки, отработанные в проекте
*   **Работа с REST API:** парсинг JSON-ответов, обработка ошибок сети.
*   **ООП:** проектирование архитектуры из 8 классов (Main, PlaceSearch, Country, City, Currency, Weather и др.), использование статических методов (`@staticmethod`).
*   **Базы данных:** проектирование схемы SQLite, работа с внешними ключами, написание запросов (INSERT, SELECT, LEFT JOIN) для сохранения и вывода истории.
*   **GUI:** создание многооконного интерфейса, обработка событий, валидация ввода, работа с таймерами.

## 🚀 Функционал приложения
*   Поиск по названию страны или города (с обработкой неоднозначных названий).
*   Отображение флага, курса валют, официальных языков и общей информации.
*   Показ местоположения на карте (через браузер).
*   Прогноз погоды в виде таблицы и графика (динамика температуры).
*   Электронные часы с местным временем выбранного города.
*   История поиска (сохраняется в БД и отображается в таблице).

## 📂 Структура репозитория
*   `src/` — исходный код приложения (8 классов).
*   `resources/` — вспомогательные файлы:
    *   `.cache.sqlite` — кэш геоданных.
    *   `history_db` — база данных SQLite для истории поиска.
    *   `country.csv`, `languages.txt` — справочники стран и языков.
    *   `background_corr.jpg`, `flag.png` — графические ресурсы для интерфейса.
    *   `Main.spec`, `requirements.txt`, `Ui_MainWindow.ui` — файлы конфигурации и сборки.
